Как пользоваться

Каждый файл — готовый графический макет страницы. Синие пунктирные бейджи Mp* — соответствующие компоненты библиотеки mp-ui-kit: вёрстка страницы собирается из них. Внизу каждого макета — таблица «Блок → компонент → props/примечание» и ключевые состояния (loading / empty / error). Текстовые спецификации и логика — в ../<имя>.md.

Соответствие слоёв FSD при вёрстке

app/**/page.tsx — только композиция · widgets/* — блоки макета (таблица, шапка, форма) · features/* — действия («Перенести», «Внести результат», «Сохранить») · shared/ui — точка применения темы над mp-ui-kit; прямой импорт @mui/* запрещён (см. fsd.md §3). Недостающий компонент добавляется в mp-ui-kit, а не дублируется в web.
