## Блоки и компоненты

| Блок                | Компонент MUI                           | Данные / логика                                                                                                                                                        |
|---------------------|-----------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Поиск/фильтры       | `InputBase` (debounce 300 мс), `Select` | URL-параметры; `features/get-doctor-patients` → `GET /api/bff/scheduling/appointments/doctor/patients` — **doctorId из токена** (пациенты — distinct из записей врача) |
| Таблица пациентов   | `shared/ui/table`                       | `widgets/patients-table` (переиспользование) + пагинация `usePagination`                                                                                               |
| Ссылка на документы | `Button text` «Открыть»                 | → `/doctor/patients/:id`                                                                                                                                               |
| Список документов   | `shared/ui/table`                       | `widgets/patient-documents`: название, категория (`Chip`), дата, автор; данные — `GET /api/bff/patient/:id/documents`                                                  |
| Загрузка            | `Button contained` + зона `drop` (Box)  | `features/upload-patient-document` → `POST /api/bff/patient/:id/doc` (multipart); прогресс `LinearProgress`; категория выбирается в диалоге перед загрузкой            |
| Скачивание          | `IconButton` + `Tooltip`                | `features/download-patient-document` → presigned-ссылка (TTL 5 мин), владелец/`ADMIN`/врач с приёмом                                                                   |

## Состояния

| Состояние                   | Поведение                                                                                       |
|-----------------------------|-------------------------------------------------------------------------------------------------|
| loading                     | Скелетон строк / карточки                                                                       |
| empty (нет пациентов)       | «У вас пока нет пациентов с приёмами» → «К приёмам»                                             |
| empty (нет документов)      | «Документов нет» + подсказка «Загрузите направление или результат анализа»                      |
| upload: неверный тип/размер | Тост с причиной («Только PDF/JPEG/PNG, до 5 МБ») — объект не создан (валидация 4.4)             |
| upload: ошибка сети         | Тост + «Повторить», файл остаётся в зоне drop                                                   |
| forbidden                   | 403: пациент не относится к врачу (нет приёма) или роль не `DOCTOR` — [403](README.md#403--404) |
| success                     | Тост «Документ загружен», строка добавляется (invalidation)                                     |

## Логика

- Право доступа проверяется **на бэке дважды**: gateway (роль `DOCTOR`) и `file-service` (связь «врач–пациент» через
  `scheduling`) — UI это не решает (9.3).
- Категория (`ANALYSIS`/`REFERRAL`/`DISCHARGE`/`OTHER`) — обязательный параметр загрузки, попадает в
  `document.uploaded.v1` (`category`, `uploadedBy`).
- Скачивание — presigned GET TTL 5 мин; истёкшая ссылка → повторный запрос, не битый файл (4.5).
- Истёкшая/отменённая связь (запись удалена) → следующий запрос документа → 403, список блокируется.
