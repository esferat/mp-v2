## Блоки и компоненты

| Блок | Компонент MUI | Источник / логика |
|---|---|---|
| Шапка | `AppBar` (elevation 0, граница снизу) | Слева: кнопка Drawer (< 960), название «MP Admin-Panel» (ADMIN) / «Медицинский портал» (USER) — из реестра меню `shared/config` + title страницы ([2.1](../functional-spec.md#21-слой-widgetslayout-шапка-меню-заголовок--m)); справа: аватар с инициалами (`shared/ui/avatar`), меню профиля, кнопка «Выйти» → `signOut` Auth.js ([1.1](../functional-spec.md#11-вход-в-web-через-keycloak-authjs--l)) |
| Боковое меню | `Drawer` (persistent ≥ 960, temporary < 960) + `List`/`ListItemButton` | Пункты фильтруются по ролям из сессии; активный пункт — `selected`, иконки Tabler/MUI |
| Заголовок страницы | `Box` + `Typography variant="h5"` | Каждая страница задаёт title (`metadata`/`shared` store); справа — корзина действий страницы (кнопки) |
| Контент | `Container maxWidth="xl"` + `Box` | Только композиция `widgets`; внутренние отступы — токены темы |
| Меню профиля | `Menu` + `MenuItem` | «Профиль», «Выйти»; role-guard на пункты |

## Состояния

- **loading:** после входа контент — скелетон до готовности сессии.
- **403:** страница без меню-гейта (см. [README](README.md#403--404)).
- **Сессия истекла:** редирект на `/auth/login?callbackUrl=…`, тост «Сессия истекла».

## Навигация

- ADMIN: `/admin/doctors`, `/admin/patients`*, `/admin/schedule`, `/admin/reports`*, `/admin/specializations`* (*пациенты, специализации и отчёты — этапы 2, 1 и 4; в Этапе 1 пункты без макета или заглушка).
- USER: `/cabinet/profile`*, `/cabinet/record`, `/cabinet/history`.
- DOCTOR (Этап 2, [9.1](../functional-spec.md#91-роль-doctor-и-учётная-запись-врача--m)): `/doctor/schedule`, `/doctor/patients` — секция добавляется в меню вместе с ролью.
- Защита: серверный гард ([1.3](../functional-spec.md#13-серверные-гарды-маршрутов-web--m)); скрытие пункта ≠ защита.
