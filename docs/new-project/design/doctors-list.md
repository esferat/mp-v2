## Блоки и компоненты

| Блок | Компонент MUI | Данные / логика |
|---|---|---|
| Заголовок + действие | `Typography h5` + `Button startIcon` | Кнопка → `/admin/doctors/new` |
| Поиск | `InputBase` с иконкой (debounce 300 мс) | `features/search-doctors` → `GET /api/catalog/doctors?search=`; сброс — `IconButton` |
| Фильтры | `Select` (spec, status) | Опции из `GET /api/catalog/specializations` (кэш) |
| Таблица | `TableContainer` + `Table` + `TableHead/Body` (обёртка `shared/ui/table`) | `widgets/doctors-table`; колонки по макету; `loading` → скелетон 10 строк |
| Фото | `shared/ui/avatar` (инициалы, если ключа нет) | presigned `photoUrl` (TTL 5 мин) |
| Статус | `Chip` (success/default) | `ACTIVE`/`INACTIVE`, из `entities/doctor` |
| Пагинация | `TablePagination` (server-side, offset/limit) | `usePagination`; назад/вперёд по 10, без кумулятивного дублирования |
| Действия | `IconButton` + `Menu` | Редактировать → `/:id`; архивировать → `Dialog`-подтверждение → `update-doctor` |

## Состояния

| Состояние | Поведение |
|---|---|
| loading | Скелетоны строк |
| empty (нет врачей) | `EmptyState`: «Врачей пока нет» + кнопка «Создать врача» |
| empty (поиск) | «По запросу „…" ничего не найдено» + «Сбросить» |
| error | Тост + «Повторить»; таблица остаётся с прошлыми данными |
| после действия | Инвалидация списка; лёгкая подсветка изменённой строки |

## Логика
- Ссылка на карточку — клик по строке или «✎»; `rowId` в URL (deep-link, F5 работает).
- Обновление списка извне (`doctor.updated.v1` из другого вкладки/админа) → тихая инвалидация.
- Права: `USER` по прямой ссылке → 403.
