## Общие правила макетов

**Стек представления:** Material UI (см. [2.2](../functional-spec.md#22-sharedui-дизайн-система-на-material-ui--l)), слои FSD ([fsd.md](../fsd.md)): страница (`app/**/page.tsx`) → `widgets` → `features` → `shared/ui`.

**Сетка и адаптив** (MUI breakpoints):

| Диапазон | Поведение |
|---|---|
| ≥ 1280 (desktop) | Сайдбар развёрнут (240 px), контент на всю ширину, таблицы с колонками по макету |
| 960–1279 | Сайдбар свёрнут в иконки (72 px), второстепенные колонки (id, дата регистрации) скрываются |
| < 960 | Сайдбар — выдвижная Drawer по кнопке-гамбургеру; таблицы — вертикальный список карточек; формы в одну колонку |

**Состояния каждой страницы (обязательны во всех макетах):**

| Состояние | Реализация |
|---|---|
| `loading` | Скелетоны MUI (таблица — 10 строк, карточка — 6 линий) вместо спиннера-центра |
| `empty` | `EmptyState`: иконка + текст «Ничего не найдено» + действие (например, «Создать врача») |
| `error` | Тост (Snackbar) с текстом + `requestId` + кнопка «Повторить»; критично — страница ошибки |
| `forbidden` | Страница 403 (нет роли) — см. [errors](#403--404) |
| `optimistic` | Действие применяется сразу, при ошибке — откат + тост |

**Источники данных:** данные приходят через `shared/api` (типы из `packages/contracts`) — в браузере клиент обращается **только к BFF `/api/bff/*`** сервера `web` ([architecture.md §6.1](../architecture.md#61-bff-и-ssr-web-как-backend-for-frontend)), пути вида `/api/<service>/...` в макетах — это контракты gateway, которые BFF вызывает на сервере; состояние таблиц — server state + invalidation, пагинация — `shared/lib/usePagination` (offset/limit, 10 строк).

**Доступность:** все действия доступны с клавиатуры, у таблиц — заголовки колонок, у иконочных кнопок — `aria-label`, у форм — связанные `label`.

## 403 / 404

```
┌──────────────────────────────────────────────────────────────┐
│  header + сайдбар (или без сайдбара для 404)                 │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │                        403                                │ │
│ │        У вас нет прав для просмотра этой страницы         │ │
│ │                  [На главную]                             │ │
│ └──────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```
404 — аналогично («Страница не найдена»), плюс ссылка в меню. Обе — корневые `app/not-found.tsx` и `app/error.tsx`; 403 — отдельная страница `app/403/page.tsx` (маршрут `/403`), см. [2.4](../functional-spec.md#24-страницы-ошибок-403404--обработчик-ошибок--m).
