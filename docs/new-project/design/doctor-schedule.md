# Страница: Кабинет врача — приёмы

**Маршрут:** `/doctor/schedule` · **Роль:** DOCTOR · **Задачи:** 9.1, 9.2

## Макет (desktop ≥ 1280)

```
┌──────────────────────────────────────────────────────────────────────────────────────────┐
│ Кабинет врача — приёмы                          [ Иванов И. И. · Хирург ]   [Выйти]      │
│──────────────────────────────────────────────────────────────────────────────────────────│
│ Период [ Сегодня ▾ ]   Статус [ Все ▾ ]                     [ Пациенты и документы → ]   │
│──────────────────────────────────────────────────────────────────────────────────────────│
│  Дата и время      Пациент           Статус          Результат        Действия          │
│  ────────────────────────────────────────────────────────────────────────────────────     │
│  05.11 09:00       Иванов П. П.      ✔ Принята       —                [Внести результат]│
│  05.11 09:30       Петрова М. А.     ✔ Приём завершён ✓ Есть           [Посмотреть]     │
│  05.11 10:00       Сидоров К. Л.     ⧗ В ожидании    —                —                │
│  06.11 09:00       Козлова Н. Н.     ✔ Принята       —                [Внести результат]│
│  …                                                                                      │
│  ────────────────────────────────────────────────────────────────────────────────────     │
│  Всего: 12        ‹  Страница 1 из 2  ›              На странице: [10 ▾]               │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

Статусы: `⧗ В ожидании (SUBMITTED)` — жёлтый `Chip`, `✔ Принята (APPROVED)` — зелёный, `✖ Отклонена` — красный,
`∅ Отменена` — серый, `✔ Приём завершён (COMPLETED)` — синий.

## Блоки и компоненты

| Блок      | Компонент MUI                                               | Данные / логика                                                                                                                                         |
|-----------|-------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------|
| Шапка     | `HeaderComponent` (2.1)                                     | имя врача и специализация — из сессии/профиля                                                                                                           |
| Фильтры   | `Select` (период: сегодня/неделя/период), `Select` (статус) | URL-параметры (F5 восстанавливает); `features/get-doctor-appointments` → `GET /api/bff/scheduling/appointments/doctor` — **doctorId берётся из токена** |
| Таблица   | `shared/ui/table`                                           | `widgets/doctor-appointments-table`, серверная пагинация по 10, сортировка по времени                                                                   |
| Пациент   | `Typography` + `Tooltip` (полное ФИО)                       | denormalized поля записи (не ходим в справочники)                                                                                                       |
| Статус    | `Chip` color по статусу                                     | `entities/appointment` (статусная машина, вкл. `APPROVED → COMPLETED`)                                                                                  |
| Результат | `Chip` «✓ Есть» / «—»                                      | наличие `visit-result` (агрегация BFF)                                                                                                                  |
| Действия  | `Button size=small`                                         | «Внести результат» — только для `APPROVED` → [visit-result.md](visit-result.md); «Посмотреть» — для `COMPLETED` (тот же диалог, режим чтения)           |

## Состояния

| Состояние | Поведение                                                                                                                                                     |
|-----------|---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| loading   | Скелетон строк                                                                                                                                                |
| empty     | «Приёмов за период нет» + «Сбросить фильтры»                                                                                                                  |
| error     | Тост + `requestId` + «Повторить»                                                                                                                              |
| forbidden | 403-страница (не `DOCTOR`) — см. [README](README.md#403--404)                                                                                                 |
| действие  | Кнопка → loading на строке; успех — `Chip` «Приём завершён» + тост; 409 (запись уже не `APPROVED`) — тост «Запись уже обработана» + тихая перезагрузка строки |

## Логика

- Видны **только свои** записи: `doctorId` из токена, параметр запроса игнорируется (защита 9.2).
- Дата «сегодня» выделяется заголовком-группой; прошедшие приёмы без результата подсвечиваются (`warning`) — «просрочен
  результат».
- Обновление после действий: инвалидация по событию/focus/таймеру 60 с (как в [history.md](history.md)), без вебсокетов
  на MVP.
