## Блоки и компоненты

| Блок             | Компонент MUI                                  | Данные / логика                                                                                                   |
|------------------|------------------------------------------------|-------------------------------------------------------------------------------------------------------------------|
| Фильтры          | `Select` ×3 (дата — `DatePicker`/период)       | URL-параметры; `features/get-my-appointments`                                                                     |
| Таблица          | `shared/ui/table`                              | `GET /api/scheduling/appointments/me` — **patientId берётся из токена**, параметр в запросе игнорируется для USER |
| Статус           | `Chip` (как в [appointments](appointments.md)) | Цвета: зелёный/красный/серый                                                                                      |
| Причина отказа   | `Typography body2 color=text.secondary`        | Поле из записи; пусто → «—»                                                                                       |
| Повторная запись | `Button text` в строке (опц.)                  | → `/patient/record` с предзаполненным направлением                                                                |

## Состояния

| Состояние | Поведение                                                            |
|-----------|----------------------------------------------------------------------|
| loading   | Скелетон строк                                                       |
| empty     | «Записей пока нет» + кнопка «Записаться к врачу» → `/patient/record` |
| error     | Тост + «Повторить»                                                   |

## Логика

- Сортировка: дата убывание; будущие записи (если есть) — сверху с бейджем «Предстоящая».
- Обновление после действий админа: приход событий `appointment.approved.v1` / `appointment.declined.v1` /
  `appointment.cancelled.v1` → инвалидация (без вебсокетов на MVP: refetch по фокусу/таймеру 60 с).
