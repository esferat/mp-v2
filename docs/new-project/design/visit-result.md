DOCTOR · **Задача:** 9.2

## Блоки и компоненты

| Блок               | Компонент MUI                               | Данные / логика                                                                                                                                |
|--------------------|---------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------|
| Шапка с контекстом | `DialogTitle` + `Typography body2`          | denormalized поля записи (пациент, дата, специализация) — без лишних вызовов API                                                               |
| Заключение         | `TextField multiline` (minRows 4) + счётчик | **обязательное**, ≤ 4000; валидация — на форме и в домене (`entities/visit-result`)                                                            |
| Рекомендации       | `TextField multiline`                       | ≤ 4000, необязательное                                                                                                                         |
| Кнопки             | `DialogActions` + `Button`                  | «Отмена» (text), «Сохранить и завершить приём» (contained, `loading` пока в запросе), защита от двойного submit (disabled после первого клика) |
| Успех              | `Snackbar` (тост) + закрытие диалога        | строка таблицы обновляется: статус `COMPLETED`, колонка «Результат» → «✓ Есть»                                                                |

## Состояния

| Состояние                                     | Поведение                                                                                                               |
|-----------------------------------------------|-------------------------------------------------------------------------------------------------------------------------|
| validation                                    | Ошибка под полем «Заключение: обязательно»; submit заблокирован                                                         |
| saving                                        | Кнопка `loading`, поля `disabled`                                                                                       |
| error (5xx)                                   | Тост + `requestId` + «Повторить»; диалог остаётся открытым, текст сохранён                                              |
| 409 (запись уже не `APPROVED` / чужая запись) | Тост «Запись уже обработана или недоступна» → закрытие + перезагрузка строки (403 — [403-страница](README.md#403--404)) |
| read-only                                     | `COMPLETED`: поля `readOnly`, тост «Результат уже внесён» при попытке прямого POST                                      |

## Логика

- Отправка: `features/enter-visit-result` → `POST /api/bff/scheduling/appointments/:id/result`; `appointmentId` из
  строки, врач — из токена (сервер проверяет связь «запись ↔ врач»).
- Одна транзакция на бэке: результат + статус `COMPLETED` + событие `appointment.completed.v1` (письмо пациенту
  подключается на Этапе 3, 6.2).
- Повторный submit идемпотентен: один результат (unique по `appointmentId`), повтор — 200 с текущим состоянием или 409,
  без дублей.
