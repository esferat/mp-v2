## Блоки и компоненты

| Блок | Компонент MUI | Данные / логика |
|---|---|---|
| Мастер | `Stepper` (3 шага) | Состояние — в `processes/booking-wizard`; назад не теряет выбор |
| Направление | `Autocomplete`/`Select` | `GET /api/catalog/specializations` |
| Дата | `DatePicker` (min=сегодня) | Ограничение на клиенте и сервере |
| Слоты по специализации | карточки врачей + `Chip`-сетка времени | `GET /api/scheduling/slots?specId&date` ([5.2](../functional-spec.md#52-слоты-по-специализации--m)); пусто → `EmptyState` «На эту дату свободных окон нет — выберите другую» |
| Подтверждение | `Dialog` (подтверждение) → `Dialog` (успех) | `POST /api/scheduling/appointments` ([5.3](../functional-spec.md#53-бронирование-записи--l)) |
| Выбор слота | `Chip` (contained/primary) | Один слот на экран, повторный выбор переключает |

## Состояния

| Состояние | Поведение |
|---|---|
| loading слотов | Скелетоны карточек врачей |
| empty | «Свободных окон нет» + смена даты |
| **409 SLOT_TAKEN** | Тост/`Alert`: «Этот слот только что заняли» → слот исчезает/становится disabled, предлагается соседний; выбор не сбрасывается |
| ошибка сети | `Dialog` остаётся открытым, кнопка снова активна, «Повторить» |
| повторный submit | Кнопка disabled до ответа (защита от двойного клика) — тест 5.6 |

## Адаптив
`< 960`: карточки врачей — в одну колонку; слоты — сетка 3–4 колонки; `Dialog` на всю ширину.
