## Блоки и компоненты

| Блок                        | Компонент MUI                                  | Данные / логика                                                                                                     |
|-----------------------------|------------------------------------------------|---------------------------------------------------------------------------------------------------------------------|
| Логотип/заголовок           | `Typography variant="h5"`                      | Бренд                                                                                                               |
| Поле email                  | `TextField` (type=email, autocomplete="email") | Zod-валидация на клиенте, `startAdornment` — иконка                                                                 |
| Поле пароль                 | `TextField` (type=password)                    | `IconButton` «показать/скрыть»                                                                                      |
| «Забыли пароль?»            | `Link`                                         | `/auth/login?mode=reset` → flow Keycloak ([1.5](../functional-spec.md#15-восстановление-пароля--m) — **после MVP**) |
| Кнопка «Войти»              | `Button variant="contained"` fullWidth         | Сабмит формы Keycloak (тема `mp-portal`); `loading` — `CircularProgress` вместо текста, кнопка disabled             |
| «Нет аккаунта? Регистрация» | `Link`                                         | → `/auth/register` → регистрация Keycloak ([1.4](../functional-spec.md#14-сага-регистрации--l))                     |
| Ошибка                      | `Alert severity="error"` над кнопкой           | Маппинг кодов: неверный пароль / нет пользователя / rate-limit → «Слишком много попыток, попробуйте через N мин»    |

## Состояния

| Состояние        | Поведение                                                                                                                                                                                                                 |
|------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| loading          | Кнопка disabled + индикатор; поля заблокированы                                                                                                                                                                           |
| error            | `Alert` с причиной; пароль не очищается; не раскрываем, какой из полей неверен                                                                                                                                            |
| rate-limit (429) | `Alert` warning с таймером повтора                                                                                                                                                                                        |
| успех            | Редирект по роли ([1.1](../functional-spec.md#11-вход-в-web-через-keycloak-authjs--l)) — на лендинг роли с описанием функционала: ADMIN → `/admin`, USER → `/patient`, DOCTOR → `/doctor`; с `callbackUrl` |

## Валидация

- email — формат, пароль — непустой (длина ≥ 8 проверяется при регистрации, здесь — не пустой).
- Enter — отправка формы, фокус-порядок: email → пароль → кнопки.

## Адаптив

`< 600`: карточка на всю ширину с отступом 16, логотип компактный.
